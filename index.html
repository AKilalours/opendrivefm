The problem

A missed object and empty road look identical

Camera-only 3D occupancy models are evaluated as though every voxel were equally observable. They are not. A rig can assign maximal confidence to free space exactly where it supplies almost no geometric evidence, because a missed object and correctly observed empty road are both, to the model, simply free.

Every published uncertainty method reads the network. Softmax probability, top-2 margin, ensembles, MC-dropout — each is a statement about a prediction that was made. None of them can say anything about a prediction that was never made at all.

The measure

One equation, one parameter, nothing learned

O(v) = maxi   ci(v) · si(v) ci(v) projected coverage min(1, (fi·r / d)2 / πfull) si(v) first-hit visibility per-pixel ray marching, no bins, no depth bias one parameter πfull = 965.0 px learned components none

Coverage says how much image area a voxel-sized object would occupy in camera i; visibility says whether the ray reaches it first. The maximum over the rig is the strength of the best geometric evidence any camera supplies for that point in space. Unlike a binary camera-observation mask it carries evidence strength, and it resolves occlusion explicitly.

Main result

The answer inverts with granularity

Question being askedModel confidenceGeometric observabilityWinner
Is this voxel wrong?0.87970.6321confidence
Is this object missed entirely?0.71930.7623geometry
Is this frame degraded?0.86180.8066confidence

This is not a tie-break, it is the finding. Confidence dominates on the question it is built for and fails on the one it structurally cannot answer. At the object level, observability comes within noise of a LiDAR point-count oracle — 0.7623 against 0.7745, a difference whose interval spans zero — while using no LiDAR at all.

Diagnostics

What is actually blocking the cameras

Measured over 400 frames by attributing every blind voxel to the thing occluding it. The ordering depends entirely on what you choose to measure, which is the same granularity trap in a different coordinate.

OccluderBy occluded volumeBy occluded road area
Buildings and structures43.9%14.3%
Vegetation27.9%5.4%
Vehicles15.7%45.4%

Measure the volume of space you cannot see and buildings dominate. Measure the area of road surface you cannot see — where anything you could actually hit is sitting — and vehicles dominate by a factor of three. Road-surface figures exclude ground-class self-occlusion, which is a ray-sampling artefact and is reported separately.

Method integrity

Pre-registered, and the negative results are reported

●

Acceptance bars set before the runs

A 4,200-line amendment log fixes every hypothesis and its acceptance threshold in advance. The test split is sealed under digest 924a44db and was opened once.

●

Two independent implementations agree to 0.0006

A z-buffer build gives +0.0521, a ray marcher sharing no geometry code gives +0.0527. The signal is in the measure, not in either implementation's bugs.

●

Three hypotheses failed and are published as failures

Calibration gap is not monotone in observability. The camera mask is marginally better at selective risk. And rebuilding the measure from predicted geometry loses the object-level advantage.

●

The last failure explains itself

Predicted occupancy is an order of magnitude denser than the true volume, so it shadows regions the rig genuinely sees. Observability at missed objects barely moves; at detected objects it collapses.

Engineering

Precomputed index table

0.329 s / frame

Output difference

0 of 30,720,000 voxels

Extrinsics and intrinsics are constant within a scene, and the whole validation split contains only two distinct camera rigs. So the ray-to-voxel index table is built twice, in 6.9 seconds, held in 832 MB, and reused across 6,019 frames. The full build fell from 114 minutes to 33.

Scope, stated plainly

An evaluation-time diagnostic, not a runtime monitor

The measure reads external scene geometry, so it cannot run on a vehicle that does not already have that geometry. We position it where it belongs: fleet-scale triage for finding where a camera-only stack is structurally blind, before deployment rather than during it. The attempt to rebuild it from the model's own predictions is reported in the paper, and it fails — that boundary is a result, not an omission.

One consequence does transfer directly to hardware. At the front camera's 1266.4 px focal length, geometric evidence saturates at 16.31 m. A loaded Class 8 tractor at 65 mph needs about 160 m to stop.
