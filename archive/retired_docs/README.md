These describe the earlier trust-aware BEV project, not SightOcc. Nothing in
the working tree references them. They are kept because they are the record of
what the project claimed before the validation harness found that several of
those claims did not reproduce.

    DISTRIBUTED_TRAINING.md        multi-GPU training notes for the old stack
    MLOPS_ONEPAGER.md              deployment one-pager for the old stack
    OpenDriveFM_Gradio_Guide.docx  user guide for the Gradio demo
    README_OLD_CLAIMS.md           the removed claims, with what replaced each
    portfolio.html                 standalone portfolio page, old framing

`README_OLD_CLAIMS.md` is the one worth reading: it is the honest record of
IoU 0.136, ADE 2.457 m, 317 FPS and "100% fault detection" being withdrawn.
